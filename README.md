# Nupa – Food Order Demo App 🍔📱

**Nupa** is a React Native demo app for ordering food. It features onboarding screens, authentication, and basic food ordering functionality in a sleek, mobile-friendly interface.

![React Native](https://img.shields.io/badge/React_Native-2025-blue) ![Expo](https://img.shields.io/badge/Expo-Managed-orange) ![MIT License](https://img.shields.io/badge/License-MIT-green)

## Features ✨

- Swipeable **Onboarding Screens**  
- **User Authentication**: Register, Login, Forgot Password  
- **Email Verification** for secure signup  
- Browse **Menu Items** and place demo orders  
- **Responsive Design** optimized for mobile
